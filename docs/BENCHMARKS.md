# Benchmarks

Correctness is primary; no comparative performance superiority is claimed.

`PYTHONPATH=src python scripts/bench.py --quick` records environment metadata plus scan/initial-sync/unchanged-plan/rename-plan/recovery/state-size observations.

`PYTHONPATH=src python scripts/scale_plan.py --paths 1000000` runs the synthetic million-path deterministic planning case without creating a million real files. The benchmark intentionally shares immutable Entry instances so it measures planner path-set/classification scale rather than object-construction overhead.

Observed local results are committed under `evidence/benchmark_local.json` and `evidence/scale_local.json` when generated by the campaign. CI correctness gates do not enforce a performance threshold.
